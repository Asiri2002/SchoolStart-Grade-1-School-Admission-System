# 🎓 SchoolStart - Grade 1 Admission System

A digital Grade 1 school admission system that simplifies the admission process for parents, schools, and education administrators.

## 📖 Overview

SchoolStart is a web and mobile-based admission management system that allows parents to apply for Grade 1 admissions online while schools and education administrators can review, approve, and manage applications efficiently.

---

# ✨ Features

## 👨‍👩‍👧 Parent Mobile App

- Parent Registration & Login
- Parent Dashboard
- Add Child Profile

- Online Application Submission
- Upload Required Documents

- Interview Schedule
- Download Admission Letter

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/your-username/SchoolStart.git
```

## Backend

```bash
cd backend
mvn spring-boot:run
```

Backend runs on:

```
http://localhost:8080
```

---

## Frontend

```bash
cd mobile-app
npm install
npx expo start
```
